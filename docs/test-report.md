## 覆盖的验收场景

- 通知、项目查询、项目详情和空搜索结果。
- 学生登录、错误密码和数据库密码哈希。
- 申请必填项校验、学号格式、截止日期和重复提交防护。
- PDF 合法上传、原始文件名保存和随机存储名。
- 非法扩展名、伪造 PDF 内容、空文件和超过 5 MB 文件拦截。
- 学生本人、辅导员和其他学生之间的材料下载权限。
- 辅导员审批意见必填、通过、退回补充材料、补传后重新待审和禁止重复审批。
- 审批结果在学生学习面板中展示。
- CSRF 开启时拒绝无安全令牌的表单。
- 安全响应头。

## 已知边界

- 本项目使用 SQLite 和本地 `uploads/` 目录，仅适合单机课程演示。
- 演示账号密码固定，正式部署前必须提供账号管理、密码重置和登录限流。
- 当前只校验文件扩展名与文件签名，不等同于生产级恶意文件扫描。
- `SECRET_KEY` 未设置时会使用进程级临时密钥，重启后会话失效。
