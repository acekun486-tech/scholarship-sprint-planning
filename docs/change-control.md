## CR-01 移除动态 SQL，改用 JSON1 参数化查询

| 项目 | 内容 |
|---|---|
| 提出时间 | 2026-11-11 |
| 提出人 | 开发 A（静态扫描发现 Bandit B608 / Ruff S608） |
| 变更原因 | `materials_by_application` 用 f-string 生成 `IN (?, ?, ...)` 占位符，当前入参来自数据库 ID，风险可控；但后续若拼接外部输入会演变为 SQL 注入，且质量门禁将 Critical 项视为阻断。 |
| 变更内容 | 把 ID 列表序列化为 JSON，通过 `json_each(?)` 在 SQLite 内部展开；保持返回字段与排序不变。 |
| 影响范围 | `app.py:162-173`；调用方为辅导员申请列表页；无 API 或模板变化。 |
| 工作量与风险 | 约 0.5 小时；风险低，需验证空列表、单申请、多申请三种情况。 |
| PO 审批 | 批准。理由：不改变用户可见行为，消除 Critical 扫描项，属于发布前必须完成的 DoD 收尾。 |
| 实施 | 在 `feature/quality-gate` 分支完成；`materials_by_application` 改用 `json.dumps(list(application_ids))` 参数。 |
| 验证 | Ruff S608 与 Bandit B608 复扫归零；`pytest -q` 全绿；辅导员材料列表与下载测试通过。 |
| 合入与基线 | 随质量修复一并合并 `main`，纳入 `v1.0.0`；无版本号递增（发布前变更）。 |
| 关闭时间 | 2026-11-15 23:52 |

## CR-02 拆分上传校验并引入字段长度常量

| 项目 | 内容 |
|---|---|
| 提出时间 | 2026-11-15 |
| 提出人 | 开发 A（Radon 圈复杂度 12、Ruff PLR0911） |
| 变更原因 | `upload_material` 同时处理文件存在性、扩展名、大小、空文件、签名、落盘、数据库事务与跳转，8 个 return、圈复杂度 12，超过单函数 ≤10 的门槛，异常路径难以测试。 |
| 变更内容 | 新增 `ValidatedUpload` 与 `validate_upload()`，集中文件校验；路由只负责权限、事务和反馈；表单长度、审批意见长度、原始文件名长度改用常量。 |
| 影响范围 | `app.py:116-133`、`app.py:345-405`、`app.py:455-491`；上传错误提示与跳转行为保持不变。 |
| 工作量与风险 | 约 2 小时；风险中，需回归 4 类拒绝场景、成功上传、数据库失败回滚、跨用户下载。 |
| PO 审批 | 批准。理由：不改变验收标准，降低维护成本，补齐异常路径测试后才能通过质量门禁。 |
| 实施 | `feature/quality-gate` 分支；新增 `validate_upload`，路由 return 从 8 个降至 4 个，圈复杂度降至 7。 |
| 验证 | `test_upload_rejects_invalid_files`、`test_upload_rejects_file_over_five_megabytes`、`test_upload_without_file_is_rejected`、`test_upload_rolls_back_file_when_database_insert_fails` 全部通过；Radon 复扫该函数 CC=7。 |
| 合入与基线 | 合并 `main`，纳入 `v1.0.0`。 |
| 关闭时间 | 2026-11-15 23:50 |

## CR-03 项目搜索转义 LIKE 通配符

| 项目 | 内容 |
|---|---|
| 提出时间 | 2026-11-10 |
| 提出人 | 开发 B（站会障碍 OBS-04） |
| 变更原因 | 搜索直接拼接 `%关键词%`，用户输入 `%` 时返回全部项目，输入 `_` 时误匹配任意单字符，搜索语义与用户预期不符。 |
| 变更内容 | 新增 `escape_like()` 转义 `\`、`%`、`_`；SQL 改为 `LIKE ? ESCAPE '\'`，标题、描述、资格条件三个字段统一处理。 |
| 影响范围 | `app.py:136-138`、`app.py:250-262`；仅影响搜索过滤，不影响列表展示与详情。 |
| 工作量与风险 | 约 0.5 小时；风险低。 |
| PO 审批 | 批准。理由：属于验收标准中的查询行为缺陷，修复成本低。 |
| 实施 | `feature/quality-gate` 分支（与 CR-01、CR-02 同一质量分支）；补充 `%`、`_`、普通中文关键词三类断言。 |
| 验证 | 新增 `test_search_wildcards_are_escaped`；原有搜索测试通过；手工验证 `q=%` 不再返回全部项目。 |
| 合入与基线 | 合并 `main`，纳入 `v1.0.0`。 |
| 关闭时间 | 2026-11-10 16:40 |
