# Sprint Backlog（代码实现映射）

## Sprint Goal

跑通奖助学金申请核心闭环：学生查看通知和项目、提交申请与证明材料、辅导员审批、学生查看进度与结果。

## 当前 Sprint 范围

| ID | 用户故事 | 本项目实现点 | 验收依据 |
|---|---|---|---|
| US01 | 学生查看奖助学金通知 | `/notices` | 通知标题和内容可展示 |
| US02 | 学生查看可申请项目 | `/projects`、`/projects/<id>` | 项目查询、详情、资格和截止日期可展示 |
| US03 | 学生填写并提交申请表 | `/apply/<project_id>` | 服务端校验、截止日期检查、重复提交防护，提交后生成申请记录 |
| US04 | 学生上传证明材料 | `/applications/<id>/upload` | 校验扩展名、文件签名和 5 MB 限制，材料关联申请 |
| US05 | 辅导员查看和审批申请 | `/counselor/applications` | 查看申请和材料，填写审批意见并执行合法状态流转 |
| US08 | 学生查看进度和结果 | `/dashboard` | 学生只能看到本人申请、状态、意见和材料 |

## 暂缓

- US06：学院管理员汇总和上报（V2）。
- US07：学生处管理员名额维护、评审结果确认与公示。需先澄清权限边界和业务规则。
